# my_vkr

# Прогнозирование цен в потребительском ритейле

ВКР по разработке и сравнению моделей машинного обучения для прогнозирования цен товаров в ритейле.

## 📊 О проекте

Проект посвящен разработке и сравнению различных подходов к прогнозированию цен товаров в потребительском ритейле с использованием методов машинного обучения и нейронных сетей.

### Цели проекта
- Сравнить эффективность регрессионных моделей и нейросетевых подходов
- Разработать оптимальную модель для прогнозирования цен
- Оценить экономический эффект от внедрения модели

## 🗂️ Данные

**Датасет**: "Grocery inventory and sales dataset"
- **Объем**: 99,000 наблюдений, 16 признаков
- **Целевая переменная**: `Unit_Price` (цена за единицу товара)
- **Категории**: 8 уникальных категорий товаров
- **Период**: данные о продажах и запасах

### Ключевые признаки
- Product_Name, Category, Supplier_Name
- Stock_Quantity, Sales_Volume
- Reorder_Level, Inventory_Turnover_Rate
- Даты поступления и expiration

## 🛠️ Технологии

- **Python 3.x**
- **Машинное обучение**: Scikit-learn, CatBoost
- **Нейронные сети**: TensorFlow/Keras
- **Обработка данных**: Pandas, NumPy
- **Визуализация**: Matplotlib, Seaborn
- **Оптимизация**: Optuna, RandomizedSearchCV

## 📈 Модели

### Исследованные алгоритмы:
1. **Random Forest** (Случайный лес)
2. **Decision Tree** (Дерево решений)
3. **CatBoost Regressor**
4. **MLP** (Многослойный персептрон)

### Методы оптимизации:
- Random Search
- Optuna с ранней остановкой

## 📊 Результаты

### Лучшие модели (по метрике MAE):

| Модель | MAE | WAPE (%) |
|--------|-----|----------|
| CatBoost (Optuna) | 0.28 | 6.01 |
| Random Forest (Base) | 0.31 | 6.51 |
| MLP | 0.32 | 6.81 |

### Ключевые выводы:
- CatBoost с оптимизацией Optuna показал наилучшие результаты
- Random Forest демонстрирует стабильную производительность
- Нейронная сеть MLP показала сопоставимые с Random Forest результаты
- Decision Tree оказалась наименее эффективной

## 💰 Экономический эффект

Расчет потенциального экономического эффекта показал:
- **Дополнительная выручка**: 30,690.89 единиц
- Возможность оптимизации ценовой политики
- Повышение точности прогнозов на 9.7% по сравнению с базовыми моделями
